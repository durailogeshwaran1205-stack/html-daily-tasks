# Ajith Kumar Biography – HTML Project

## 📌 Project Overview

This project contains two simple **HTML pages** created to practice basic HTML concepts such as headings, paragraphs, images, links, tables, lists, audio, and video.

## 📂 Project Files

### 1. `ajithkumar.html`

This page contains:

* Ajith Kumar biography
* Heading and subheadings
* Image
* Paragraphs
* Line breaks
* Hyperlink
* HTML table
* Movie collection details
* Family member list

### 2. `index.html`

This page contains:

* Ajith Kumar biography
* HTML heading and paragraph
* Video player
* Audio player
* Basic HTML structure

## 🛠️ Technologies Used

* HTML5

* `<html>`

## 📁 Suggested Folder Structure

```text
Ajith-Kumar-Biography/
│
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Make sure the `img` folder contains `video.mp4` and `audio.mpeg`.
4. Use the link in the HTML page to navigate between the pages.
